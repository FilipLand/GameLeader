# GameLeader
Trabajo de proyecto Filip, David, Guillermo

# **1\. Visión General y Objetivos**

GameLeader es una plataforma web (aplicación cliente-servidor) orientada a la catalogación, seguimiento (tracking) y evaluación de videojuegos, adoptando un modelo análogo al de Letterboxd.
El objetivo de la plataforma es ofrecer una interfaz de usuario (UI) fluida para la gestión de bibliotecas lúdicas, respaldada por un sistema backend escalable,
con baja latencia en la recuperación de datos y una arquitectura de base de datos relacional robusta.
